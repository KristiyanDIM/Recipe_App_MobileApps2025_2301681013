# Cook Book – Mobile Recipe App

**Cook Book** е мобилно приложение за Android, което позволява на потребителите да съхраняват, редактират и организират своите рецепти на едно място.  
Приложението е разработено с фокус върху **чиста архитектура**, **сигурност** и **модерен потребителски интерфейс**.

## Основни функционалности

- ✅ **Добавяне на рецепта** – заглавие, съставки, инструкции + снимка от камерата
- ✅ **Преглед на всички рецепти** – подреден списък с RecyclerView
- ✅ **Редактиране на рецепта** – промяна на текст или нова снимка
- ✅ **Изтриване на рецепта** – с потвърждение чрез диалогов прозорец
- ✅ **Автоматичен Light / Dark режим** – следва системните настройки
- ✅ **Актуализация в реално време** – LiveData + Flow

## Архитектура на приложението

Приложението следва **MVVM (Model-View-ViewModel)** архитектурен модел, допълнен с **Repository** слой:
### 🔹 Слой за данни (Model)
- **Entity** – `Recipe.kt` (заглавие, съставки, инструкции, път към снимка)
- **DAO** – `RecipeDao.kt` (SQL заявки с анотации `@Insert`, `@Update`, `@Delete`, `@Query`)
- **Database** – `AppDatabase.kt` (Singleton инстанция на Room DB)

### 🔹 Repository слой
- `RecipeRepository.kt` – единна входна точка за данните
- Скрива сложността на базата от UI слоя
- Улеснява бъдещо добавяне на API / облачна синхронизация

### 🔹 ViewModel слой
- `RecipeViewModel.kt` – посредник между данните и UI
- Използва `viewModelScope` за асинхронни операции
- Съхранява данни при завъртане на екрана

### 🔹 UI слой (View)
- `MainActivity` – контейнер с навигация (Single Activity)
- `HomeFragment` – списък с рецепти (RecyclerView + Adapter)
- `AddRecipeFragment` – добавяне на нова рецепта
- `DetailRecipeFragment` – преглед, редактиране, изтриване

## Как работи интеграцията с камерата

Приложението използва **Explicit Intent** за заснемане на снимки:

1. Създава се временен файл в частното хранилище
2. Чрез **FileProvider** се генерира сигурен `content://` URI
3. Изпраща се `Intent(MediaStore.ACTION_IMAGE_CAPTURE)` с `EXTRA_OUTPUT`
4. Камерата записва директно пълното изображение
5. Пътят към снимката се запазва в базата данни

 Спазени са съвременните изисквания за сигурност на Android (API 24+).
